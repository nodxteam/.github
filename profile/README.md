# Nodx

We build Discord bots, automation scripts, and websites. Based on real project
work — not templates.

---

### What we do

**Discord bots** — custom bots built around what the server actually needs.
Moderation, economy, leveling, integrations, whatever the use case requires.

**Automation & scripts** — tools that cut out repetitive work. Scrapers,
schedulers, API bridges, deployment helpers, internal tooling.

**Websites** — from landing pages to full-stack web apps. We pick the stack
that fits the project, not the one that's trendy.

---

### Open source

We publish the tools and libraries we build when they're worth sharing.

### Stack

We work across multiple languages depending on what the job calls for.
